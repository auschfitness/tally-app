# Domínios semânticos UBS: espanhol → português

Entrada: `scripts/ubs/work/domains.input.json` = `[{ code, es }]` (nomes de domínio e
subdomínio do Louw-Nida, ex. "Actividades Religiosas", "Bautizar").
Saída: `scripts/ubs/work/domains.pt.json` = `[{ code, pt }]`, mesma ordem, mesmo `code`.

Traduza você mesmo (proibido usar Bash, Python, Node ou qualquer script; só Read e Write).
Português do Brasil, rótulo curto, só a primeira letra maiúscula ("Atividades religiosas",
"Batizar"). Nomes próprios no nome usual em português.
